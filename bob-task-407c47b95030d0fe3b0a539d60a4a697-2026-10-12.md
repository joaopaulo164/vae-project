======================================================================
1. OBJETIVO DA MODIFICAÇÃO
======================================================================

Atualmente, o comando de comparação de dimensões latentes consegue treinar
um VAE independente para cada dimensão definida em uma lista, salvar os
checkpoints, registrar o histórico de treinamento e consolidar as losses.

Amplie esse comando para que ele também gere automaticamente todas as
evidências científicas de cada dimensão após o treinamento.

O comando existente deve continuar sendo utilizado:

python -m vae_project.cli compare-latent-dims \
    --config configs/latent_dimensions_mnist.yaml

E, para Fashion-MNIST:

python -m vae_project.cli compare-latent-dims \
    --config configs/latent_dimensions_fashion_mnist.yaml

O fluxo completo para cada dimensão deve passar a ser:

configuração
→ criação do VAE
→ treinamento
→ validação
→ seleção do melhor checkpoint
→ carregamento do melhor checkpoint
→ extração das representações latentes
→ geração das visualizações adequadas
→ cálculo das métricas subsidiárias
→ geração das tabelas
→ geração do manifesto
→ geração do resumo da execução
→ consolidação dos resultados de todas as dimensões

Não implemente somente uma geração de figuras desconectada do treinamento.

======================================================================
2. DIMENSÕES LATENTES
======================================================================

As configurações de comparação devem continuar aceitando uma lista como:

latent_dimension_comparison:
  enabled: true
  fixed_topology: medium
  dimensions:
    - 2
    - 8
    - 16
    - 32

Cada item da lista representa um treinamento independente.

Não altere `model.latent_dimension` para aceitar uma lista.

O campo abaixo deve continuar representando a dimensão de um único modelo:

model:
  latent_dimension: 16

A lista de dimensões deve permanecer exclusivamente no bloco de comparação.

O comportamento esperado é:

- dimensão 2: treinar um VAE com espaço latente 2D;
- dimensão 8: treinar outro VAE com espaço latente 8D;
- dimensão 16: treinar outro VAE com espaço latente 16D;
- dimensão 32: treinar outro VAE com espaço latente 32D.

Não reutilize o mesmo modelo entre dimensões.

Para cada dimensão:

1. reinicialize completamente o modelo;
2. recrie o otimizador;
3. recrie o scheduler, quando aplicável;
4. recrie o early stopping;
5. aplique novamente a configuração de reprodutibilidade;
6. treine de forma independente;
7. selecione o melhor checkpoint com base na validation total loss.

======================================================================
3. EXPERIMENTO NÃO SUPERVISIONADO
======================================================================

A comparação completa das dimensões 2, 8, 16 e 32 pertence ao experimento
principal não supervisionado.

As configurações padrão utilizadas pelo comando devem manter:

supervised_component:
  enabled: false

Quando o componente supervisionado estiver desabilitado:

- os rótulos não devem participar da função de custo;
- os rótulos não devem influenciar a atualização dos pesos;
- a classification loss não deve ser calculada ou deve ser registrada
  explicitamente como zero, conforme o padrão já adotado pelo projeto;
- os rótulos podem ser utilizados somente após o treinamento para:
  - colorir as projeções;
  - identificar as classes;
  - calcular métricas subsidiárias;
  - auxiliar a interpretação dos resultados;
- os artefatos devem ser identificados como `unsupervised`.

Não habilite automaticamente o componente supervisionado.

O experimento supervisionado será executado manualmente pelo usuário, em
uma configuração independente, depois da seleção da dimensão latente.

A modificação não deve remover a capacidade atual do projeto de executar
o componente supervisionado em outros comandos.

- a mesma topologia;

A única variável experimental deve ser a dimensão latente.

======================================================================
6. MELHOR CHECKPOINT
======================================================================

As evidências devem ser geradas utilizando o melhor checkpoint de cada
dimensão, e não o estado da última época.

Para cada dimensão, implemente ou preserve o seguinte fluxo:

1. treinar o modelo;
2. avaliar a validation total loss por época;
3. aplicar early stopping;
4. salvar o checkpoint da melhor época;
5. concluir o treinamento;
6. carregar novamente o melhor checkpoint;
7. verificar se o checkpoint corresponde à dimensão atual;
8. colocar o modelo em modo de avaliação;
9. extrair as representações latentes;
10. gerar as evidências.

Não gere projeções a partir do modelo da última época quando ela não for a
melhor época.

O checkpoint deve preservar, no mínimo:

- estado do modelo;
- estado relevante do treinamento;
- dimensão latente;
- topologia;
- melhor época;
- validation reconstruction loss;
- validation KL divergence;
- validation total loss;
- seed;
- dataset;
- tipo do experimento.

"""Artifact manifest: tracks all files generated in a run.

Ensures transparency and reproducibility by recording every output
file with its purpose, creation date, run context and (optionally) hash.
"""

from __future__ import annotations

import hashlib
import json
import logging
from datetime import datetime
from pathlib import Path

logger = logging.getLogger(__name__)


class ArtifactManifest:
    """Records and persists all artifacts generated in an experiment run.

    Args:
        run_dir: Root directory of the experiment run.
        context: Optional constant values (e.g. latent_dimension, dataset,
            seed, experiment_type) copied into every entry and into the
            manifest header.
    """

    def __init__(self, run_dir: Path, context: dict[str, object] | None = None) -> None:
        self.run_dir = Path(run_dir)
        self.context: dict[str, object] = dict(context or {})
        self._entries: list[dict[str, object]] = []
        self._execution_status: str | None = None
        self._errors: list[dict[str, str]] = []

    def set_execution_status(
        self,
        status: str,
        errors: list[dict[str, str]] | None = None,
    ) -> None:
        """Record the overall execution status and any errors in the header.

        Args:
            status: 'completed', 'partial' or 'failed'.
            errors: Failure records (operation, error, probable_cause).
        """
        self._execution_status = status
        self._errors = list(errors or [])

    def _build_entry(
        self,
        file_path: Path,
        artifact_type: str,
        description: str,
        compute_hash: bool,
    ) -> dict[str, object]:
        """Build one manifest entry for ``file_path``."""
        exists = file_path.exists()
        entry: dict[str, object] = {
            "path": file_path.relative_to(self.run_dir).as_posix(),
            "artifact_type": artifact_type,
            "description": description,
            "exists": exists,
            "status": "present" if exists else "missing",
            "size_bytes": file_path.stat().st_size if exists else 0,
            "created_at": (

                if exists
                else None
            ),
        }
        entry.update(self.context)
        if compute_hash and exists:
            entry["sha256"] = _compute_file_hash(file_path)
        return entry

        file_path: Path,
        artifact_type: str,
        description: str,
        compute_hash: bool = False,
    ) -> None:
        """Register a generated file in the manifest.

        Args:
            file_path: Path to the generated file.
            artifact_type: Category (e.g. 'figure', 'table', 'checkpoint').
            description: Human-readable description of the artifact.
            compute_hash: Whether to compute the SHA-256 hash.
        """
        self._entries.append(
            self._build_entry(Path(file_path), artifact_type, description, compute_hash)
        )

                        artifact_type,

                        compute_hash=False,

        Returns:
            Path to the saved manifest file.
        """
        manifest_path = self.run_dir / "artifact_manifest.json"

            hasher.update(chunk)
    return hasher.hexdigest()

def resolve_topology(config: ExperimentConfig) -> TopologyConfig:
    """Return the fixed topology used by every model of the comparison.

    The topology comes from ``model.topology``. ``fixed_topology`` must name it,

    if topology.name != fixed_name:

            f"model.topology.name='{topology.name}'. The comparison uses one fixed topology."

def _relative(path: Path | None, base: Path) -> str | None:
    """Return ``path`` relative to ``base`` using forward slashes."""
    if path is None:
        return None
    return Path(path).relative_to(base).as_posix()


def _first_relative(paths: list[Path], suffix: str, base: Path) -> str | None:
    """Return the first path with ``suffix`` relative to ``base``, or None."""
    for path in paths:
        if path.suffix == suffix:
            return _relative(path, base)
    return None

def run_latent_dimension_comparison(
    config: ExperimentConfig,
    output_dir: Path,
    dimensions: list[int] | None = None,
    splits: DataSplits | None = None,
) -> pd.DataFrame:
    """Train each latent dimension independently and generate its evidence.

    Holds constant: dataset, topology, seed, learning rate, batch size,
    max epochs, early stopping, loss definition, data splits, projection
    parameters and sampling.

    A failure in one dimension is recorded and does not stop the others; failed
    dimensions never take part in the best-dimension statement.

    Args:
        config: Base experiment configuration.
        output_dir: Directory for comparison artifacts.
        dimensions: Latent dimensions to compare. Defaults to
            ``config.latent_dimension_comparison.dimensions``.
        splits: Optional pre-built data splits (used by tests to avoid
            downloads). When None, the configured dataset is loaded.

    Returns:
        Consolidated comparison table sorted by ``latent_dimension``.

    Raises:
        LatentDimensionComparisonError: If the comparison is disabled, the
            dimensions are invalid, the topology is inconsistent, or no
            dimension finished training.
    """
    if not config.latent_dimension_comparison.enabled:
        raise LatentDimensionComparisonError(
            "latent_dimension_comparison.enabled is false; nothing to run."
        )

    compare_dims = list(dimensions or config.latent_dimension_comparison.dimensions)
    dimension_errors = validate_comparison_dimensions(compare_dims)
    if dimension_errors:
        raise LatentDimensionComparisonError("; ".join(dimension_errors))

    topology = resolve_topology(config)
    output_dir = ensure_dir(Path(output_dir))
    setup_logging(config.logging, log_file=output_dir / "latent_dimension_comparison.log")

    device = get_device(config.runtime.device, config.runtime.cuda_fallback_to_cpu)

    if splits is None:
        train_full, test_dataset = get_raw_datasets(
            dataset_name=config.dataset.name,
            data_dir=config.paths.data_dir,
            download=config.dataset.download,
        )
        splits = create_data_splits(
            train_full_dataset=train_full,
            test_dataset=test_dataset,
            dataset_name=config.dataset.name,
            splits_config=config.splits,
            quick_mode=config.project.quick_mode,
        )
    # One split and one set of loaders for all dimensions.
    loaders = create_data_loaders(
        splits=splits,
        training_config=config.training,
        dataset_config=config.dataset,
    )

    runner = _DimensionRunner(config, topology, output_dir, device, splits, loaders)
    records: list[DimensionRunRecord] = []
    for latent_dim in compare_dims:
        record = runner.run(latent_dim)
        records.append(record)
        logger.info("latent_dim=%d finished with status=%s", latent_dim, record.status)

    table = build_comparison_table(records)
    output_csv = output_dir / "latent_dimension_comparison.csv"
    write_comparison_summary(records, output_dir)
    table.to_csv(output_csv, index=False)
    logger.info("Latent dimension comparison saved: %s", output_csv)

    if all(record.status == STATUS_FAILED for record in records):
        raise LatentDimensionComparisonError(
            f"All latent dimensions failed for dataset={config.dataset.name.value}. "
            f"See {output_dir / 'latent_dimension_comparison_summary.md'} and the "
            "per-dimension logs."
        )
    return table
